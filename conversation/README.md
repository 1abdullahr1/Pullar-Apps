# Conversation History and Artifacts

This directory contains the development logs, conversation transcripts, implementation plans, and walkthroughs for the Pullar project.

## Transcript Files

- `transcript.jsonl`: Compact conversation actions and trajectory log in JSON Lines format.
- `transcript_full.jsonl`: Complete, untruncated conversation transcript log.

## Artifacts and Plans

- `android_implementation_plan.md`: Initial architecture and implementation plan for the native Android app.
- `android_v2_features_plan.md`: Plan for ABI split packaging, Material You theming, inline M3 media player, and animated splash screen.
- `android_v2_walkthrough.md`: Verification and release details for Android v1.2.0.
- `pullar_website_plan.md`: Design and implementation specification for the Astro landing page and download portal.
- `walkthrough.md`: Release notes and verification walkthrough for Pullar desktop and web releases.
